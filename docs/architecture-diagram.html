DetLab-DAC Architecture

Detection Engineering Workbench composed of a Typer CLI, FastAPI backend, Next.js dashboard, scoring and ATT&CK analytics engines, reusable detection packs, multi-backend export modules, and a local startup path for fast demo and evaluation.

Workflow Story

  • • detection content is loaded from repo YAML
  • • CLI and API both exercise the same validation, scoring, and export logic
  • • Next.js surfaces the resulting analytics as recruiter-friendly visuals
  • • local startup scripts keep the demo path fast and reproducible

Detection Engineering Focus

  • • validate detections before shipping
  • • score quality and false-positive risk
  • • map ATT&CK tactics, techniques, and gaps
  • • export detections into Splunk, Sigma, KQL, and EQL

Demo Surfaces

  • • dashboard overview and ATT&CK heatmap
  • • detection quality ranking view
  • • pack browser and coverage summaries
  • • CLI reports and API JSON payloads for automation
