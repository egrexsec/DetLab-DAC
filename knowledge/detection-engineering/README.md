# Detection Engineering

Store detection documentation artifacts here.

Each entry should help a detection engineer answer:
- what behavior is being detected
- what telemetry is required
- how the detection maps to ATT&CK
- what the canonical analytic model is
- how the logic translates across Sigma, SPL, KQL, EQL, ES|QL, or another platform dialect
- which platform fields map back to canonical fields
- what false positives to expect
- how an analyst should triage and validate the detection

Reference the canonical schema at:
- `docs/schema/canonical-detection-schema.md`
